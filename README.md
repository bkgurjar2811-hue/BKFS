# BKFS Management

Work in progress: loan and collection management for Android and web.

The current local implementation is a browser prototype, not a production application or Android APK. It includes customer, loan, collection, staff and report screens.

Do not enter real customer data in the prototype. Server authentication, protected storage, correct amortization schedules, device approval and Android packaging still need implementation and verification. The demo login uses browser storage and does not provide a security boundary.

No live deployment or verified APK is available yet.
